# Phần 1: SSH & Socket Connections

## 1. SSH là gì ?

SSH = Secure Shell

Nó cho phép một máy client kết nối tới một máy server để :

- đang nhập từ xa
- chạy command
- truyền file
- quản lý server

**Mô hình :**

```text
+-------------+        TCP        +-------------+
| SSH Client  | ----------------> | SSH Server  |
|   Ubuntu    |                   |   Ubuntu    |
+-------------+                   +-------------+

                         sshd : 22
```

Thông thường SSH Server lắng nghe trên : TCP/22

Process server thường có tên : sshd

## 2. Socket là gì ?

Một socket là endpoint cho việc giao tiếp mạng.

Có thể hình dung : IP + Port + Protocol

Ví dụ : 192.168.1.50:22/TCP

Một kết nối TCP có thể được biểu diễn bằng :

```text
Client                          Server
------------------------------------------------
192.168.1.100:43001   --->   192.168.1.50:22
                TCP (SSH)
```

Trong W01-D03 có :

```text
port 42111
port 42112
port 42113
```

> đây thường là **source của client**, không phải của SSH server port

ví dụ : "Failed password for root from 192.168.1.50 port 42111 ssh2"

có thể hiểu là :

```text
User = root
Source IP = 192.168.1.50
Source port = 42111
Protocol = SSH
```

server SSH vẫn có thể đang nghe : TCP/22

## 3. Kiểm tra socket trên Ubuntu

```bash
ss -tuln
```

giải thích :

```text
ss
│
├── -t → TCP
├── -u → UDP
├── -l → listening
└── -n → hiển thị số, không resolve hostname
```

ví dụ output :

```text
LISTEN 0 128 0.0.0.0:22 0.0.0.0:\*
```

> điều đó có nghĩa là service đang LISTEN trên TCP port 22

### 3.1. Nếu Ubuntu chưa chạy SSH server

kiểm tra :

```bash
systemctl status ssh
```

Nếu chưa có :

```bash
sudo apt install openssh-server
```

sau đó

```bash
sudo systemctl enable --now ssh
```

kiểm tra :

```bash
ss -tln | grep ':22'
```

sau đó có thể thấy :

```text
LISTEN ... :22 ...
```

## 4. Xem process sshd

chạy :

```bash
ps aux | grep '[s]shd'
```

tại sao dùng: `'[s]shd'` thay vì `ssh`

nếu dùng :

```bash
grep sshd
```

thì chính process `grep sshd` cũng có thể xuất hiện

# Phần 2: SSH Brute-Force Mechanics

## 1. SSH login bình thường

```text
Client
│
│ TCP connection
↓
Server:22
│
│ SSH handshake
↓
Authentication
│
├── Success → session
│
└── Failure → log event
```

## 2. Brute-force (tấn công vét cạn)

> thử tất cả các khả năng cho đến khi tìm đúng

```text
Attacker
│
├── password 1 → FAIL
├── password 2 → FAIL
├── password 3 → FAIL
├── password 4 → FAIL
├── password 5 → FAIL
│
└── password N → ?
```

> nếu xảy ra liên tục trong thời gian ngắn thì SOC có thể tạo detection

## 3. Password spraying khác brute-force

**Password spraying :**

> là một dạng tấn công mà attacker dùng 1 password và thử trên nhiều tài khoản khác nhau

Brute-force :

> một account :

```text
root
├── password1
├── password2
├── password3
├── password4
```

Password spraying :

> một password thử trên nhiều account :

```text
Password123

root
admin
test
hieu
user
```

**Vì vậy khi phân tích log, cần phải tự hỏi:**

> Ai -> thử account nào -> từ IP nào -> trong khoảng thời gian nào ?

## 4. Tại sao log quan trọng

Một ssh attack xảy ra trên network nhưng sau đó tạo ra artifact ở hệ thống :

```text
Network
↓
SSH connection
↓
sshd
↓
Authentication
↓
auth log
```

ví dụ :

```text
Failed password for root from 192.168.1.50
```

nên khi SOC viết report :

```text
Source IP
Username
Time
Authentication result
```

# Phần 3: Regex Pipelines

regex = cách mô tả một pattern trong text

## 1. Regex dùng để làm gì?

nếu có log :

```text
Oct 03 10:01:01 server sshd[2001]: Failed password for root from 192.168.1.50 port 41001 ssh2
```

nếu muốn tìm "Failed password" thì dùng `grep` với lệnh :

```bash
grep "Failed password" ssh_bruteforce.log
```

Nhưng muốn tìm mọi IP, ví dụ :

```text
192.168.1.50
10.10.10.20
172.16.0.15
```

ta cần một pattern mô tả :

```text
số.số.số.số
```

> cần regex

## 2. Regex cơ bản

**`.` - một ký tự bất kỳ**

ví dụ :

```bash
grep "c.t" file
```

có thể match với :

```text
cat
cut
...
```

**`^` - bắt đầu dòng**

ví dụ :

nếu có log :

```text
Oct 03 10:01:01 server sshd[2001]: Failed password for root from 192.168.1.50 port 41001 ssh2
Oct 03 10:01:02 server sshd[2002]: Failed password for root from 192.168.1.50 port 41002 ssh2
Oct 03 10:01:03 server sshd[2003]: Failed password for root from 192.168.1.50 port 41003 ssh2
```

```bash
grep "^Oct" ssh_bruteforce.log
```

thì sẽ trả ra cả 3 dòng vì có "Oct" đứng đầu

nhưng nếu :

```bash
grep "Failed" ssh_bruteforce.log
```

thì sẽ không trả ra gì cả vì không có dòng nào bắt đầu bằng "Failed"

**`$` - cuối dòng**

```bash
grep "ssh2$" ssh_bruteforce.log
```

thì sẽ trả ra cả 3 dòng vì có "ssh2" đứng cuối

nhưng nếu :

```bash
grep "Failed" ssh_bruteforce.log
```

thì sẽ không trả ra gì cả vì không có dòng nào kết thúc bằng "Failed"

**`*` - lặp 0 hoặc nhiều lần**

ví dụ :

```bash
grep "fo*" file.log
```

có thể match với :

```text
fo
foo
fooo
foooo
fooooo
....
```

**`[ ]` - một trong các ký tự trong ngoặc**

ví dụ :

```bash
grep "c[au]t" file.log
```

có thể match với :

```text
cat
cut
```

(nghĩa là a hoặc u)

**`[0-9]` - một chữ số từ 0-9**

giả sử có file log.txt :

```text
Oct 5 10:15:32 server sshd[1234]: Failed password for root from 192.168.1.10 port 54321 ssh2
Oct 5 10:15:35 server sshd[1235]: Failed password for admin from 10.0.0.5 port 44444 ssh2
Oct 5 10:15:40 server sshd[1236]: Accepted password for hieu from 172.16.0.2 port 55555 ssh2
```

```bash
grep '[0-9]' log.txt
```

output sẽ là cả 3 dòng vì dòng nào cũng có số

ta có tương tự với [a-z] và [A-Z]

chú ý :

| regex    | ý nghĩa                        |
| -------- | ------------------------------ |
| [0-9]    | 1 chữ số                       |
| [0-9]+   | >= 1 chữ số                    |
| [0-9]{4} | chỉ có đúng 4 chữ số liên tiếp |
| [0-9]\*  | 0 hoặc nhiều chữ số            |

**`?` - 0 hoặc 1 lần xuất hiện**

```bash
grep "ab?c" file.log
```

có thể match với :

```text
ac
abc
```

> b có thể có hoặc không

## 3. Regex quan trọng : IP

nếu muốn nhận diện : 192.168.1.50

ta dùng :

```bash
grep -E '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+'
```

> Ở đây `\.` dùng để bỏ qua dấu `.` trong IP bởi vì khi dùng `grep` thì `.` đại diện cho 1 ký tự bất kỳ nên mình phải bỏ qua

## 4. Regex với `grep -o`

> chỉ in phần được match

ví dụ log có

```text
Oct 03 10:01:01 server sshd[2001]: Failed password for root from 192.168.1.50 port 41001 ssh2
Oct 03 10:01:02 server sshd[2002]: Failed password for root from 192.168.1.50 port 41002 ssh2
Oct 03 10:01:03 server sshd[2003]: Failed password for root from 192.168.1.50 port 41003 ssh2
Oct 03 10:01:04 server sshd[2004]: Failed password for admin from 192.168.1.50 port 41004 ssh2
Oct 03 10:01:05 server sshd[2005]: Failed password for root from 10.10.10.20 port 42001 ssh2
Oct 03 10:01:06 server sshd[2006]: Failed password for root from 10.10.10.20 port 42002 ssh2
Oct 03 10:01:07 server sshd[2007]: Failed password for test from 10.10.10.20 port 42003 ssh2
Oct 03 10:01:08 server sshd[2008]: Failed password for admin from 172.16.0.15 port 43001 ssh2
Oct 03 10:01:09 server sshd[2009]: Failed password for admin from 172.16.0.15 port 43002 ssh2
Oct 03 10:01:10 server sshd[2010]: Accepted password for hieu from 192.168.1.100 port 44001 ssh2
```

```bash
grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' ssh_bruteforce.log
```

output:

```text
192.168.1.50
192.168.1.50
192.168.1.50
192.168.1.50
10.10.10.20
10.10.10.20
10.10.10.20
172.16.0.15
172.16.0.15
192.168.1.100
```

## 5. Phân tích pipeline từng bước

```text
grep "Failed password"
↓
Chỉ lấy failed SSH login
↓
grep -Eo "IP regex"
↓
Chỉ lấy IP
↓
sort
↓
Đưa IP giống nhau cạnh nhau
↓
uniq -c
↓
Đếm
↓
sort -nr
↓
IP nhiều nhất lên đầu
```

```bash
grep "Failed password" ssh_bruteforce.log | grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' | sort | uniq -c | sort -nr
```

output

```text
4 192.168.1.50
3 10.10.10.20
2 172.16.0.15
```

# Phần 4: `sed` và `awk`

## 1. `sed` là gì ?

`sed` = Stream Editor

> dùng để đọc từng dòng text rồi tìm, thay thế, xóa hoặc chỉnh sửa dòng đó

**Cấu trúc :**

```bash
sed 's/OLD/NEW/' file
```

trong đó :

```text
s = substitute
OLD = nội dung cần tìm
NEW = nội dung thay thế
```

## 2. `sed` không sửa file mặc định

ví dụ :

```bash
sed 's/root/admin/' ssh_bruteforce.log
```

> chỉ in ra kết quả đã thay đổi ra màn hình terminal chứ trong file gốc thì vẫn như cũ

nếu muốn sửa trực tiếp file :

```bash
sed -i 's/root/admin/' ssh_bruteforce.log
```

> khi học SOC, không được tùy tiện `-i` trên log thật. Log là evidence (chứng cứ), không nên tự ý thay đổi

## 3. Một số lệnh `sed` cơ bản

**Thay thế**

```bash
sed 's/root/admin' file.log # thay thế root bằng admin
```

**Xóa một dòng**

```bash
sed '/Accepted/d' file.log # xóa dòng chứa Accepted
```

d = delete

**Chỉ xem dòng cụ thể**

```bash
sed -n '1p' ssh_bruteforce
```

`-n` = không tự động in ra tất cả các dòng
`'1p'` = in ra dòng 1

ví dụ : in từ dòng 1 đến dòng 3 :

```bash
sed -n '1,3p' ssh_bruteforce.log
```

## 4. SOC dùng `sed` để làm gì?

ví dụ có log :

```text
Failed password for root from 192.168.1.50
```

bạn muốn thay username để tạo dữ liệu test :

```bash
sed 's/root/admin/g' ssh_bruteforce.log # trong dòng có chỗ nào là root thì thay bằng admin, nếu không có g thì có thể chỉ thay thế 1 từ root
```

trong log analysis thực tế, sed thường dùng để :

```text
raw log
   ↓
sed làm sạch/chuẩn hóa
   ↓
awk phân tích field
   ↓
sort / uniq
   ↓
alert
```

## 5. `awk`

> công cụ xử lý text theo cột/field và điều kiện

nếu có dòng log :

```text
Oct 03 10:01:01 server sshd[2001]: Failed password for root from 192.168.1.50 port 41001 ssh2
```

Tách field :

```text
$1     Oct
$2     03
$3     10:01:01
$4     server
$5     sshd[2001]:
$6     Failed
$7     password
$8     for
$9     root
$10    from
$11    192.168.1.50
$12    port
$13    41001
$14    ssh2
```

Lấy username :

```bash
awk '{print $9}' ssh_bruteforce.log
```

Lấy IP :

```bash
awk '{print $11}' ssh_bruteforce.log
```

## 6. Kết hợp `grep` và `awk`

chỉ lấy ip của những lần đăng nhập thất bại :

```bash
grep "Failed password" ssh_bruteforce.log | awk '{print $11}'
```

## 7. `awk` lọc theo điều kiện

**cú pháp :**

```bash
awk 'điều kiện {hành động}' file.log
```

ví dụ : chỉ lấy dòng có IP 192.168.1.50

```bash
awk '$11 == "192.168.1.50" {print}' ssh_bruteforce.log
```

## 8. Lấy nhiều field cùng lúc

nếu vừa muốn xem IP và username :

```bash
awk '{print $11, $9}' ssh_bruteforce.log
```

có thể thêm text vào cho đẹp mắt :

```bash
awk '{print "IP:", $11, "Username:", $9}' ssh_bruteforce.log
```

## 9. Ví dụ

vd : IP nào đang brute-force vào tài khoản root?

```bash
awk '$9 == "root" {print $11}' ssh_bruteforce.log | sort | uniq -c | sort -nr
```

# Phần 5: `awk` nâng cao

## 1. `$0`, `NF`, `NR`

**`$0` - in ra toàn bộ dòng chứa pattern cần tìm**

> in nguyên dòng chứ không phải in riêng từng field

```bash
awk '$9 == "root" {print $0}' ssh_bruteforce.log
```

> in ra những dòng có $9 = root

**`NF` - có bao nhiêu field**

> in ra số field của mỗi dòng

```bash
awk '{print NF}' ssh_bruteforce.log
```

output :

```text
14
14
14
14
14
14
14
14
```

**`NR` - số thứ tự dòng**

```bash
awk '{print NR, $0}' ssh_bruteforce.log
```

output :

```text
1 Oct 03 10:01:01 server sshd[2001]: Failed password for root from 192.168.1.50 port 41001 ssh2
2 Oct 03 10:01:02 server sshd[2002]: Failed password for root from 192.168.1.50 port 41002 ssh2
3 Oct 03 10:01:03 server sshd[2003]: Failed password for root from 192.168.1.50 port 41003 ssh2
4 Oct 03 10:01:04 server sshd[2004]: Failed password for admin from 192.168.1.50 port 41004 ssh2
5 Oct 03 10:01:05 server sshd[2005]: Failed password for root from 10.10.10.20 port 42001 ssh2
6 Oct 03 10:01:06 server sshd[2006]: Failed password for root from 10.10.10.20 port 42002 ssh2
7 Oct 03 10:01:07 server sshd[2007]: Failed password for test from 10.10.10.20 port 42003 ssh2
8 Oct 03 10:01:08 server sshd[2008]: Failed password for admin from 172.16.0.15 port 43001 ssh2
9 Oct 03 10:01:09 server sshd[2009]: Failed password for admin from 172.16.0.15 port 43002 ssh2
10 Oct 03 10:01:10 server sshd[2010]: Accepted password for hieu from 192.168.1.100 port 44001 ssh2
```

## 2. Điều kiện - khi chưa biết field

**In ra số thứ tự của field và giá trị của field**

```bash
awk '{for (i=1; i<=NF; i++) print i, $i}' ssh_bruteforce.log
```

output của 1 dòng :

```text
1 Oct
2 03
3 10:01:10
4 server
5 sshd[2010]:
6 Accepted
7 password
8 for
9 hieu
10 from
11 192.168.1.100
12 port
13 44001
14 ssh2
```

**Tìm địa chỉ IP khi chỉ biết giá trị của field trước đó**

```bash
awk '{for (i=1; i<=NF; i++) if($i=="port") print $(i-1)}' ssh_bruteforce.log
```

**Toán tử so sánh**

| Toán tử | Ý nghĩa           |
| ------- | ----------------- |
| `==`    | bằng              |
| `!=`    | khác              |
| `>`     | lớn hơn           |
| `<`     | nhỏ hơn           |
| `>=`    | lớn hơn hoặc bằng |
| `<=`    | nhỏ hơn hoặc bằng |

## 3. Regex trong `awk`

**Cú pháp :**

```bash
awk '$field ~ /regex/ {action}' file.log
```

ví dụ : tìm những ip có bắt đầu bằng 192.168

```bash
awk '$11 ~ /^192\.168/ {print $0}' ssh_bruteforce.log
```

**Khi không biết field nào chữa thông tin**

```bash
awk '$0 ~ /Failed password/ {print $0}' ssh_bruteforce.log
```

tương đương :

```bash
awk '/Failed password/ {print $0}' ssh_bruteforce.log
```

> tìm những dòng chứa "Failed password"

Ngược lại tìm những dòng không chứa "Failed password" :

```bash
awk '$0 !~ /Failed password/ {print $0}' ssh_bruteforce.log
```

**Regex trên 1 field**

```bash
awk '$9 ~ /^r/' ssh_bruteforce.log
```

> tìm những dòng có username bắt đầu bằng r
> root

**Regex + điều kiện**

ví dụ : Những failed password từ mạng 192.168.x.x

```bash
awk '$6 == "Failed" && $11 ~ /192\.168/ {print $0}' ssh_bruteforce.log
```

**Nếu không biết field của IP**

> có thể dùng $0 + regex

```bash
awk '/Failed/ && /192\.168/ {print $0}' ssh_bruteforce.log
```

**Khi các field không được chia bằng những khoảng trắng**

FS - Field Separator

vd có log : user,192.168.1.50,failed,ssh

```bash
awk -F',' '{print $1}' file.log
```

output : user

**OFS - output field separator**

khi :

```bash
awk '{print $11, $9}' ssh_bruteforce.log
```

output :

```text
192.168.1.50 root
192.168.1.50 root
192.168.1.50 root
192.168.1.50 admin
10.10.10.20 root
10.10.10.20 root
10.10.10.20 test
172.16.0.15 admin
172.16.0.15 admin
192.168.1.100 hieu
```

nếu :

```bash
awk 'BEGIN {OFS=" -> "} {print $11, $9}' ssh_bruteforce.log
```

output :

```text
192.168.1.50 -> root
192.168.1.50 -> root
192.168.1.50 -> root
192.168.1.50 -> admin
10.10.10.20 -> root
10.10.10.20 -> root
10.10.10.20 -> test
172.16.0.15 -> admin
172.16.0.15 -> admin
192.168.1.100 -> hieu
```

## 4. BEGIN và END

```text
BEGIN {
    # chạy 1 lần trước khi đọc file
}

{
    # xử lý từng dòng
}

END {
    # chạy 1 lần sau khi đọc hết file
}
```

vd :

```bash
awk 'BEGIN {count = 0} /Failed/ {count++} END {print "Failed attempts:", count}' ssh_bruteforce.log
```

## 5. `awk` có thể tự đếm mà không cần `uniq -c`

```bash
awk '/Failed password/ {count[$11]++}
END {
    for (ip in count)
        print count[ip], ip
}' ssh_bruteforce.log
```
