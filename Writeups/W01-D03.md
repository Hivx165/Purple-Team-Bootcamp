# Phần 1 - grep Mastery

## 1. grep là gì ?

- là chương trình dùng để tìm các dòng chứa một mẫu (pattern) trong :
  - file văn bản
  - log hệ thống
  - hoặc đầu ra của lệnh khác

(hình dung `grep` giống `ctrl + F`)

ví dụ bạn có file log

```bash
INFO User admin logged in
ERROR Database connection failed
WARNING Disk almost full
ERROR Invalid password
```

muốn tìm tất cả các dòng chứa `ERROR` :

input:

```bash
grep "ERROR" app.log
```

output :

```bash
ERROR Database connection failed
ERROR Invalid password
```

**cú pháp** : `grep [option] "pattern" file`

trong đó :

| Thành phần | Ý nghĩa                      |
| ---------- | ---------------------------- |
| grep       | chương trình tìm kiếm        |
| [option]   | tùy chọn                     |
| "pattern"  | chuỗi hoặc biểu thức cần tìm |
| file       | file cần tìm                 |

giả sử file "app.log" có nội dung :

```bash
INFO User admin logged in
ERROR Database connection failed
INFO File uploaded
WARNING Disk almost full
ERROR Invalid password
INFO Logout successful
```

khi sử dụng lệnh : `grep "ERROR" app.log` -> grep đọc từng dòng, nếu có "ERROR" thì in ra, không thì bỏ qua

## 2. option `-i` - không phân biệt chữ hoa hay chữ thường

khi sử dụng lệnh : `grep -i "ERROR" app.log`

> kết quả :

    - error
    - ERROR
    - Error

dùng khi : SOC thường dùng khi log từ nhiều hệ thống không thống nhất cách viết

## 3. option `-n` hiển thị pattern ở dòng số bao nhiêu :

input:

```bash
grep -n "ERROR" app.log
```

ouput :

```bash
2:ERROR Database connection failed
5:ERROR Invalid password
```

## 4. option `-c` - số kết quả

input:

```bash
grep -c "ERROR" app.log
```

ouput :

```bash
2
```

## 5. option `-v` - hiển thị những dòng không chứa pattern

input :

```bash
grep -v "ERROR" app.log
```

output:

```bash
INFO User admin logged in
INFO File uploaded
WARNING Disk almost full
INFO Logout successful
```

## 6. option `-r` - tìm pattern trong nhiều file

Tạo thư mục:

```bash
mkdir logs
cp app.log logs/system.log
cp app.log logs/auth.log
```

input :

```bash
grep -r "ERROR" logs/
```

=> grep sẽ tìm hết các file trong /logs

=> lệnh BlueTeam dùng rất nhiều

## 7. Regex cơ bản

**^ - bắt đầu dòng :**

lệnh : `grep "^ERROR" app.log`

ouput :

```bash
ERROR Database connection failed
ERROR Invalid password
```

=> chỉ lấy khi "ERROR" đứng đầu dòng

**$ - kết thúc dòng :**

lệnh : `grep "failed$" app.log`

output :

```bash
ERROR Database connection failed
```

**. - đại diện cho 1 kí tự bất kỳ**

lệnh : `grep "ERRO." app.log`

có thể : ERROR, ERROx,...

## 8. grep -E

`-E` là biểu thức chính quy mở rộng

lệnh : `grep -E "ERROR|WARNING" app.log`

=> dùng như OR

output :

```bash
ERROR Database connection failed
WARNING Disk almost full
ERROR Invalid password
```

## 9. grep với Pipe

đây là cách dùng nhiều trong thực tế

vd :

```bash
cat app.log | grep "ERROR"
```

`|` có thể hiểu là lấy output của lệnh bên trái làm input cho lệnh bên phải

lệnh trên tương tự với :

```bash
grep "ERROR" app.log
```

# Phần 2 - head, tail và less

## 1. head

> hiển thị 10 dòng đầu

cú pháp :

```bash
head [option] file
```

**`-n` - lấy số dòng :**

cú pháp :

```bash

```

hoặc

```bash
head -3 file # lấy 3 dòng đầu
```

## 2. tail

> hiển thị 10 dòng cuối
> trong SOC, log mới nhất thường nằm ở cuối file

cú pháp :

```bash
tail [option] file
```

**`-n` - lấy số dòng :**

cú pháp :

```bash
tail -n 3 file # lấy 3 dòng cuối
```

hoặc

```bash
tail -3 file # lấy 3 dòng cuối
```

## 3. `tail -f` - Theo dõi log thời gian thực

`-f` = Follow

> Thay vì kết thúc sau khi hiển thị, Terminal sẽ đợi log mới xuất hiện.

chạy :

```bash
tail -f server.log
```

> thì terminal sẽ đứng im
> nếu trên 1 terminal khác mà nhập 1 log mới thì trên màn hình terminal đã chạy lệnh `tail -f server.log` sẽ hiển thị thêm những log mới nhập

## 4. `less` - đọc file lớn

**Vì sao cần `less`**

so sánh

| Lệnh | Hành vi    |
| ---- | ---------- |
| cat  | in toàn bộ |
| less | mở để cuộn |

với file hàng trăm MB

```bash
less /var/lag/syslog
```

**Cách dùng `less`**

mở :

```bash
less server.log
```

**Các thao tác**

| Phím  | Chức năng         |
| ----- | ----------------- |
| space | xuống 1 trang     |
| b     | lên một trang     |
| Enter | xuống 1 dòng      |
| q     | thoát             |
| /     | tìm kiếm          |
| n     | kết quả tiếp theo |
| N     | kết quả trước     |

**tìm kiếm trong les**

```bash
/
```

nhập : ERROR

nhấn : `n` để tới kết quả tiếp theo

## 5. Kết hợp với `grep`

```bash
grep "ERROR" server.log | head -3
```

**Quy trình**

|Server|--------|`grep "ERROR"`|--------|`head -3`|--------|3|

- grep đọc lỗi
- head lấy 2 lỗi đầu tiên

## 6. Điều tra log thật trên Ubuntu

**Xem cuối log hệ thống**

```bash
tail -20 /var/log/syslog
```

nếu Ubuntu không có syslog, dùng :

```bash
journalctl -n 20
```

## 2. Ba luồng quan trọng: stdin / stdout / stderr

linux process thường có 3 stream:

              PROCESS
                 |
                 |

---

| | |
| | |
stdin stdout stderr
| | |
input output error

**`stdin` - file descriptor 0**
input đi vào chương trình

ví dụ :

```bash
cat < users.txt
```

> `users.txt` trở thành input của `cat`

**`stdout` - file descriptor 1**
output bình thường của chương trình

ví dụ :

```bash
ls
```

> danh sách file được in ra terminal -> đó là `stdout`

**`stderr` - file descriptor 2**

```bash
ls /abcxyz
```

có thể nhận :
`ls: cannot access '/abcxyz': No such file or directory`

> đây là `stderr`

## 3. Pipe

cú pháp :

```bash
command1 | command2
```

**Ý nghĩa**

> lấy `stdout` của command1 làm `stdin` cho command2

vd :

```bash
ls /ect | grep ssh
```

Luồng :

ls /etc
│
│ stdout
▼
|
▼
grep ssh
│
▼
chỉ giữ dòng có "ssh"
