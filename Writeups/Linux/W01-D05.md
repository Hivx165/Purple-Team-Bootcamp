# Phần 1 : Bash fundamentals

## 1. Bash script là gì ?

> bash script là một file chứa nhiều lệnh shell để máy tính thực hiện tuần tự. Bạn có thể bổ sung biến, điều kiện, vòng lặp và xử lý lỗi để tự động hóa công việc

ví dụ, thay vì nhập nhiều lệnh kiểm tra một host, có thể tạo chương trình :

```text
host_discovery.sh
        │
        ▼
Nhận IP từ người dùng
        │
        ▼
Kiểm tra IP hợp lệ
        │
        ▼
Gửi ICMP ping
        │
        ▼
In kết quả
```

Trong Purple Team :

- Red : có thể dùng script để kiểm tra khả năng kết nối tới các host trong phạm vi được cho phép
- Blue/SOC : có thể dùng scipt để thu thập dữ liệu ban đầu và hỗ trợ điều tra
- DevSecOps : dùng shell scipt để tự động hóa kiểm tra và các bước trong pipline

## 2. File Bash script

Tạo file :

```bash
nano hello.sh
```

Nội dung :

```bash
#!/usr/bin/env bash # đây là shebang, cho hệ điều hành biết sử dụng Bash để chạy file khi bạn thực thi nó trực tiếp

echo "Hello, Purple Team!" # echo in nôi dung ra terminal
echo "Today I am learning Bash scripting."
```

Chạy script bằng một trong 2 cách :

Cách 1 : gọi trực tiếp

```bash
bash hello.sh
```

Cách 2 : cấp quyền thực thi rồi chạy

```bash
chmod +x hello.sh
./hello.sh # ./ là chạy file trong thư mục hiện tại
```

## 3. Biến trong Bash

> Biến dùng đẻ lưu giá trị mà script có thể sử dụng lại

ví dụ :

```bash

name="hieu"
target="127.0.0.1"

echo "User: $name"
echo "Target: $target"
```

output:

```text
User: hieu
Target: 127.0.0.1
```

> khi gán giá trị cho biến, không đặt khoảng trắng quanh dấu =

Đúng :

```bash
target="127.0.0.1"
```

Sai :

```bash
target = "127.0.0.1"
```

> nếu tách ra thì có thể hiểu là `target` là một từ khóa lệnh chứ không phải biến

## 4. Argument - nhận dữ liệu từ command line

> thay vì sửa mã lệnh mỗi lần muốn đổi IP, chúng ta truyền IP vào lúc chạy chương trình

Tạo file :

```bash
nano args.sh
```

Nội dung :

```bash
#!/usr/bin/env bash

echo "Script name: $0"
echo "First argument: $1"
echo "Second argument: $2"
echo "All argument: $@"
echo "Number of argument: $#"
```

output :

```text
Script name: args.sh
First argument: 192.168.1.10
Second argument: 8080
All arguments: 192.168.1.10 8080
Number of arguments: 2
```

Trong đó :

| Cú pháp | ý nghĩa                                                                             |
| ------- | ----------------------------------------------------------------------------------- |
| $0      | tên script                                                                          |
| $1      | đối số thứ nhất                                                                     |
| $2      | đối số thứ 2                                                                        |
| $@      | tất cả đối số, được giữ thành từng đối số riêng khi đặt trong dấu ngoặc kép phù hợp |
| $#      | số lượng đối số                                                                     |
| $?      | Exit code của command chạy ngay trước đó                                            |

Thực tế :

```bash
bash host_discovery.sh 192.168.1.10
```

## 5. Điều kiện `if` và exit code

> script cần biết một thao tác có thành công hay không để quyết định bước tiếp theo

ví dụ :

```bash
#!/usr/bin/env bash

if [[ -f "hello.sh" ]]; then
    echo "File exists"
else
    echo "File does not exist"
fi
```

Giải thích:

| cú pháp  | ý nghĩa                                                        |
| -------- | -------------------------------------------------------------- |
| [[....]] | đánh giá biểu thức điều kiện trong bash                        |
| -f       | kiểm tra đường dẫn có phải file thông thường tồn tại hay không |
| then     | chạy khối lệnh nếu điều kiện đúng                              |
| else     | chạy khi điều kiện sai                                         |
| fi       | kết thúc cấu trúc if                                           |

ví dụ khác :

```bash
if [[ $# -lt i ]]; then
    echo "Usage: bash script.sh<target>"
    exit 1
fi
```

Trong đó :

| cú pháp | ý nghĩa                                          |
| ------- | ------------------------------------------------ |
| $#      | số lượng đối số                                  |
| -lt     | nhỏ hơn (less than)                              |
| exit 1  | kết thúc script với mã lỗi quy ước là 1          |
| exit 0  | thường biểu thị chương trình kết thúc thành công |

Bạn có thể kiểm tra exit code của command vừa chạy :

```bash
bash hello.sh
echo $?
```

# Phần 2 : Loops trong Bash

> vòng lặp cho phép thực hiện một công việc nhiều lần mà không cần viết lại cùng một câu lệnh. Trong purple team, chúng ta sẽ dùng vòng lặp để kiểm tra nhiều IP, xử lý danh sách máy chủ và tổng hợp kết quả

## 1. Vòng lặp for

ví dụ :

```bash
#!/usr/bin/env bash

for name in Alice Bod Charlie; do
    echo "Hello, $name"
done
```

output:

Hello, Alice
Hello, Bob
Hello, Charlie

Trong đó :

| Cú pháp         | ý nghĩa                            |
| --------------- | ---------------------------------- |
| for name in ... | gán lần lượt giá trị cho biến name |
| do              | bắt đầu phần lệnh được lặp lại     |
| echo            | in ra terminal                     |
| done            | kết thúc vòng lặp                  |

## 2. Lặp qua danh sách IP

```bash
#!/usr/bin/env bash

for ip in 127.0.0.1 192.168.1.1 192.168.1.10; do
    echo "Checking target :$ip"
done
```

chạy file :

```bash
bash loop_ips.sh
```

output :

Checking target: 127.0.0.1
Checking target: 192.168.1.1
Checking target: 192.168.1.10

## 3. Vòng lặp for với danh sách đối số

> bash có thể lặp qua tất cả đối số người dùng truyền vào bằng "$@" :

```bash
#!/usr/bin/env bash

for target in "$0";do
    echo "Target: $target"
done
```

chạy file :

```bash
bash loop_ips 127.0.0.1 192.168.1.10
```

## 4. Vòng lặp while

> for duyệt qua danh sách, còn while lặp lại lệnh khi điều kiện vẫn còn đúng

ví dụ :

```bash
#!/usr/bin/env bash

count=1

while [[ $count -le 5 ]]; do
    echo "Count: $count"
    count=$((count+1))
done
```

output :

Count: 1
Count: 2
Count: 3
Count: 4
Count: 5

## 5. Kết hợp while với đọc file

giả sử bạn có file targets.txt :

127.0.0.1
192.168.1.10
10.0.0.5

```bash
#!/usr/bin/env bash

while IFS= read -r target; do
    echo "Target" $target"
done < target.txt
```

Trong đó :

| cú pháp           | ý nghĩa                                                   |
| ----------------- | --------------------------------------------------------- |
| read -r target    | đọc một dòng và lưu vào biến target                       |
| -r                | ngăn bash xử lý dấu `\` như ký tự escape                  |
| IFS=              | tránh việc `read` loại bỏ khoảng trắng ở đầu và cuối dòng |
| done < target.txt | chuyển nội dung file làm đầu vào cho vòng lặp             |

> mỗi dòng trong file được xử lý một lần

> xử lý danh sách IP từ file thay vì nhập thủ công từng IP

Nếu dòng cuối không có newline (là ký tự xuống dòng, giúp máy tính biết rằng một dòng đã kết thúc và dòng tiếp theo bắt đầu) thì :

```bash
#!/usr/bin/env bash

while IFS= read -r target || [[ -n "$target" ]]; do
    echo "Target : $target"
done < targets.txt
```

## 6. Kiểm tra điều kiện trong vòng lặp

```bash
for target in 127.0.0.1 192.168.1.10 10.0.0.5; do
    if [[ "$target" == "127.0.0.1"]]; then
        echo "$target is local host"
    else
        echo "$target is another target"
    fi
done
```

output :

127.0.0.1 is localhost
192.168.1.10 is another target
10.0.0.5 is another target

## 7. Dùng `ping` kiểm tra một host

```bash
ping -c 3 -W 2 127.0.0.1
```

Trong đó :

| cú pháp   | ý nghĩa                                                               |
| --------- | --------------------------------------------------------------------- |
| ping      | gửi ICMP Echo Request để kiểm tra khả năng phản hồi                   |
| -c 3      | gửi tối đa 3 gói                                                      |
| -W 2      | chờ tối đa 2 giây cho mỗi phản hồi trước khi coi là hết thời gian chờ |
| 127.0.0.1 | địa chỉ loopback của chính máy hiện tại                               |

> lưu ý về bảo mật : ping thành công không chứng minh tất cả dịch vụ trên máy đều hoạt động; ping thất bại cũng không chứng minh máy đã tắt, vì ICMP có thể bị chặn

## 8. Mini lab - host_check.sh

Nội dung :

```bash
#!/usr/bin/env bash

for target in 127.0.0.1 192.168.1.10 10.0.0.5; do
    echo "Checking $target ..."

    if ping -c 1 -W 2 "$target" > /dev/null 2>&1; then
        echo "[+] $target is responding"
    else
        echo "[-] $target did not respond"
    fi

    echo
done
```

Trong đó :

```bash
if ping -c 1 -W 2 "$target" > /dev/null 2>&1; then
```

| thành phần | ý nghĩa                                           |
| ---------- | ------------------------------------------------- |
| ping       | gửi gói tin ICMP để kiểm tra phản hồi             |
| c -1       | gửi 1 gói tin                                     |
| -W 2       | chờ phản hồi tối đá 2 giây cho gói tin trên linux |
| "$target"  | địa chỉ IP đang được kiểm tra                     |
| >          | chuyển hướng đầu ra                               |
| /dev/null  | nơi loại bỏ dữ liệu đầu ra                        |
| 2>&1       | chuyển lối chuẩn sang cùng nơi với đầu ra chuẩn   |
